# Reglas del proyecto

- Nunca ejecutar firebase deploy.
- Nunca utilizar el proyecto estacion-azul-web de producción.
- Trabajar únicamente en DEV.
- Nunca modificar ni leer archivos .env.*.local.
- Nunca tocar credenciales, backups o cuentas de servicio.
- No borrar colecciones ni documentos.
- Antes de modificar archivos, explicar el plan.
- Realizar cambios pequeños y revisables.
- No cambiar más archivos de los solicitados.
- Ejecutar git diff --check y mostrar el diff final.
- No hacer commit ni push sin autorización.
